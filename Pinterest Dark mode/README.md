# Pinterest Actually Dark
 
A browser extension that makes Pinterest actually dark. Built at 3AM because the official dark mode doesn't work.
 
![version](https://img.shields.io/badge/version-2.6-red)
![platform](https://img.shields.io/badge/platform-Chrome%20%7C%20Opera%20GX-blue)
![made by](https://img.shields.io/badge/by-GlaSS%20Walker-darkred)
![license](https://img.shields.io/badge/license-MIT-green)
 
## Features
 
- Dark background across the entire site
- Dark header, navigation sidebar and search bar
- Dark tab bar with hover and active states
- No black squares on sidebar icons
- No white flash on board hover
- Pinterest logo stays red
## Install
 
1. Download `Pinterest_Dark_Mode.zip` from this folder
2. Unzip it
3. Open `opera://extensions` or `chrome://extensions`
4. Enable **Developer mode** (top right toggle)
5. Click **Load unpacked** and select the unzipped folder
## Known issues
 
- Pinterest updates its CSS classes frequently — some elements may break after a Pinterest update
- If something looks off, reinstall the latest version
